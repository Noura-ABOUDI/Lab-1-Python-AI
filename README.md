# Machine Learning 1 – Lab 1: Python for Machine Learning

Bilingual lab (English / Français) for M1 BDDS: Anaconda, Jupyter, Pandas, Matplotlib, Scikit-Learn.

| File | Content |
|---|---|
| `index.html` | Language chooser |
| `lab1_en.html` | English version |
| `lab1_fr.html` | Version française |
| `assets/style.css`, `assets/lab.js` | Shared styles and scripts (copy buttons, aggregated solutions) |

## View locally
Open `index.html` in a browser, or run `python -m http.server` in this folder.

## Publish with GitHub Pages
Settings → Pages → Deploy from branch → `main` / root. The lab will be at `https://<user>.github.io/<repo>/`.
