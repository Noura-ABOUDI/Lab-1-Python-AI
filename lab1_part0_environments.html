Important: Anaconda and Miniconda are distributions, while conda is the package and environment manager. VS Code and Jupyter are tools for writing and running code. They are not alternatives to Python itself.

The four main development environments

1. Python + VS Code

Recommended for learning programming
  • Install Python separately.
  • Install VS Code and the Python and Jupyter extensions.
  • Install the required libraries with pip.
  • Works for Python scripts (.py) and Jupyter notebooks (.ipynb).

Advantages: lightweight, flexible, suitable for learning Python and software development.

Show method: how to use it
  1. Install Python from python.org and check it: python --version (on Windows, try py --version).
  2. Install VS Code, then the Python and Jupyter extensions (Extensions panel, Ctrl + Shift + X).
  3. Create a project folder, open it with File → Open Folder, then open a terminal (Terminal → New Terminal).
  4. Create an isolated environment and install the libraries:
python -m venv .venv
.venv\Scripts\activate           # Windows
source .venv/bin/activate        # macOS / Linux
python -m pip install numpy pandas matplotlib scikit-learn jupyter
  1. Create Lab1_Introduction.ipynb (or a .py file). Click Select Kernel at the top right, choose the .venv interpreter, and run a cell with Shift + Enter.
If PowerShell blocks the activation script, open a Command Prompt terminal instead. To use the classic interface, run jupyter notebook in the terminal.

2. Anaconda

All-in-one
  • Includes Python, the conda package and environment manager, and a large collection of data science packages.
  • Includes Anaconda Navigator, a graphical interface to launch tools and manage environments.

Advantages: convenient for beginners who want many data science tools ready to use.

Limitation: needs more disk space and installs more packages than many projects need.

Show method: how to use it
  1. Download and install Anaconda from anaconda.com.
  2. Open Anaconda Navigator (graphical) or Anaconda Prompt (command line).
  3. Create one dedicated environment per project:
conda create -n ml-project python=3.12
conda activate ml-project
conda install numpy pandas matplotlib scikit-learn notebook
  1. In Navigator, choose ml-project in the "Applications on" list and click Launch under Jupyter Notebook. Or, in the prompt, run jupyter notebook.
Part 1 of this lab uses this workflow.

3. Miniconda

Minimal
  • A minimal installer for Python and conda.
  • You install only the libraries each project needs.

Advantages: lightweight, flexible, useful for managing several isolated environments.

Limitation: you must install your tools and libraries yourself.

Show method: how to use it
  1. Install Miniconda (the minimal installer from the Anaconda website).
  2. Open a terminal: Anaconda Prompt on Windows, or the normal terminal on macOS / Linux. If conda is not found, run conda init and reopen the terminal.
  3. Create an environment and install only what you need:
conda create -n ml-project python=3.12
conda activate ml-project
conda install numpy pandas matplotlib scikit-learn jupyter
conda env list            # see all your environments
  1. Launch Jupyter with jupyter notebook. Add a package later with conda install package_name.
There is no Navigator: everything is done in the terminal.

4. Google Colab

Online, no installation
  • An online Jupyter notebook environment.
  • Runs in a web browser, with no local Python installation.
  • Gives access to CPU and, when available, GPU or TPU runtimes.

Advantages: easy to start, convenient for sharing notebooks, useful for deep learning experiments.

Limitations: needs internet access; runtime availability and session duration are limited.

Show method: how to use it
  1. Open colab.research.google.com and sign in with a Google account.
  2. Click File → New notebook, write Python in a cell and run it with Shift + Enter.
  3. If a package is missing, install it in a cell:
%pip install scikit-learn
  1. Optional GPU: Runtime → Change runtime type, then choose a GPU (when available).
  2. Files: upload with the Files panel on the left (temporary), or mount your Google Drive:
from google.colab import drive
drive.mount('/content/drive')
Packages and uploaded files can disappear when the hosted runtime is reset. Save your notebook to Drive or download it (File → Download).

Show guidance

Python + VS Code: first Python and ML labs. You learn to install libraries, run programs, use notebooks and understand the development environment.

Anaconda: an integrated data science installation, with a graphical interface for beginners.

Miniconda: a lightweight conda setup, to learn package and environment management without unnecessary packages.

Google Colab: installation problems, or you need a GPU. Everybody can open it in a browser.

Choose one primary environment instead of installing all four. Python + VS Code is a good start if you can install software; Colab is the simplest fallback; use Miniconda later for reproducible environments and project dependencies.
