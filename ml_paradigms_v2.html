Recap in 30 seconds

Supervised

Has labels y. The model learns y = f(X) from examples with the right answer.

Category → classification (spam or not, sick or not).

Number → regression (house price, days in hospital).

Unsupervised

No labels. The algorithm finds structure in X by itself.

Groups → clustering.

Fewer columns → dimensionality reduction: extraction (new mixed columns, PCA) or selection (keep some original columns).

Reinforcement

No dataset. An agent acts in an environment and receives rewards or penalties.

It learns a policy by trial and error: the best action in each situation.

Which family? Ask in this order:
  1. Is there a label column y? Yes → supervised. Is y a category or a number? Classification or regression.
  2. No label, but you want groups or fewer columns? → unsupervised.
  3. No data yet, an agent learns from rewards by acting? → reinforcement.
