Partie 0 – Choisir son environnement de développement

Avant d’écrire du code, décidez où votre code de Machine Learning va s’exécuter. Cliquez sur un environnement ci-dessous pour voir ce qu’il est, ses avantages et ses limites, et comment l’utiliser (ouvrez « Afficher la méthode »).

Python, pip, conda et environnements : qui fait quoi ?

ComposantRôle
PythonLangage de programmation et interpréteur
pipInstalle les paquets Python
condaGère les paquets et les environnements isolés ; peut aussi gérer les versions de Python
AnacondaDistribution contenant conda et de nombreux paquets de data science présélectionnés

Important : Anaconda et Miniconda sont des distributions, tandis que conda est le gestionnaire de paquets et d’environnements. VS Code et Jupyter sont des outils pour écrire et exécuter du code. Ils ne remplacent pas Python lui-même.

Les quatre principaux environnements de développement

1. Python + VS Code

Recommandé pour apprendre la programmation
  • Installer Python séparément.
  • Installer VS Code et les extensions Python et Jupyter.
  • Installer les bibliothèques nécessaires avec pip.
  • Fonctionne pour les scripts Python (.py) et les notebooks Jupyter (.ipynb).

Avantages : léger, flexible, adapté à l’apprentissage de Python et du développement logiciel.

Afficher la méthode : comment l’utiliser
  1. Installez Python depuis python.org et vérifiez-le : python --version (sous Windows, essayez py --version).
  2. Installez VS Code, puis les extensions Python et Jupyter (panneau Extensions, Ctrl + Maj + X).
  3. Créez un dossier de projet, ouvrez-le avec Fichier → Ouvrir le dossier, puis ouvrez un terminal (Terminal → Nouveau terminal).
  4. Créez un environnement isolé et installez les bibliothèques :
python -m venv .venv
.venv\Scripts\activate           # Windows
source .venv/bin/activate        # macOS / Linux
python -m pip install numpy pandas matplotlib scikit-learn jupyter
  1. Créez Lab1_Introduction.ipynb (ou un fichier .py). Cliquez sur Select Kernel en haut à droite, choisissez l’interpréteur .venv, puis exécutez une cellule avec Maj + Entrée.
Si PowerShell bloque le script d’activation, ouvrez plutôt un terminal Invite de commandes. Pour utiliser l’interface classique, lancez jupyter notebook dans le terminal.

2. Anaconda

Tout-en-un
  • Inclut Python, le gestionnaire de paquets et d’environnements conda, et une grande collection de paquets de data science.
  • Inclut Anaconda Navigator, une interface graphique pour lancer les outils et gérer les environnements.

Avantages : pratique pour les débutants qui veulent de nombreux outils de data science prêts à l’emploi.

Limite : demande plus d’espace disque et installe plus de paquets que beaucoup de projets n’en ont besoin.

Afficher la méthode : comment l’utiliser
  1. Téléchargez et installez Anaconda depuis anaconda.com.
  2. Ouvrez Anaconda Navigator (graphique) ou Anaconda Prompt (ligne de commande).
  3. Créez un environnement dédié pour chaque projet :
conda create -n ml-project python=3.12
conda activate ml-project
conda install numpy pandas matplotlib scikit-learn notebook
  1. Dans Navigator, choisissez ml-project dans la liste « Applications on » et cliquez sur Launch sous Jupyter Notebook. Ou, dans l’invite de commandes, lancez jupyter notebook.
C’est le déroulement le plus courant avec Anaconda.

3. Miniconda

Minimal
  • Un installateur minimal pour Python et conda.
  • Vous installez uniquement les bibliothèques dont chaque projet a besoin.

Avantages : léger, flexible, utile pour gérer plusieurs environnements isolés.

Limite : vous devez installer vous-même vos outils et vos bibliothèques.

Afficher la méthode : comment l’utiliser
  1. Installez Miniconda (l’installateur minimal du site d’Anaconda).
  2. Ouvrez un terminal : Anaconda Prompt sous Windows, ou le terminal habituel sous macOS / Linux. Si conda est introuvable, lancez conda init puis rouvrez le terminal.
  3. Créez un environnement et installez seulement ce dont vous avez besoin :
conda create -n ml-project python=3.12
conda activate ml-project
conda install numpy pandas matplotlib scikit-learn jupyter
conda env list            # voir tous vos environnements
  1. Lancez Jupyter avec jupyter notebook. Ajoutez un paquet plus tard avec conda install nom_du_paquet.
Il n’y a pas de Navigator : tout se fait dans le terminal.

4. Google Colab

En ligne, sans installation
  • Un environnement de notebooks Jupyter en ligne.
  • Fonctionne dans un navigateur web, sans installation locale de Python.
  • Donne accès au CPU et, lorsque c’est disponible, au GPU ou au TPU.

Avantages : facile à démarrer, pratique pour partager des notebooks, utile pour les expériences de deep learning.

Limites : nécessite un accès à internet ; la disponibilité des environnements d’exécution et la durée des sessions sont limitées.

Afficher la méthode : comment l’utiliser
  1. Ouvrez colab.research.google.com et connectez-vous avec un compte Google.
  2. Cliquez sur Fichier → Nouveau notebook, écrivez du Python dans une cellule et exécutez-la avec Maj + Entrée.
  3. Si un paquet manque, installez-le dans une cellule :
%pip install scikit-learn
  1. GPU en option : Exécution → Modifier le type d’exécution, puis choisissez un GPU (si disponible).
  2. Fichiers : importez-les avec le panneau Fichiers à gauche (temporaire), ou montez votre Google Drive :
from google.colab import drive
drive.mount('/content/drive')
Les paquets et les fichiers importés peuvent disparaître quand l’environnement d’exécution est réinitialisé. Enregistrez votre notebook dans Drive ou téléchargez-le (Fichier → Télécharger).

Afficher l’indication

Python + VS Code : premiers TP de Python et de ML. Vous apprenez à installer des bibliothèques, exécuter des programmes, utiliser des notebooks et comprendre l’environnement de développement.

Anaconda : une installation de data science intégrée, avec une interface graphique pour les débutants.

Miniconda : une installation conda légère, pour apprendre la gestion des paquets et des environnements sans paquets inutiles.

Google Colab : en cas de problème d’installation, ou si vous avez besoin d’un GPU. Tout le monde peut l’ouvrir dans un navigateur.

Choisissez un seul environnement principal au lieu d’installer les quatre. Python + VS Code est un bon début si vous pouvez installer des logiciels ; Colab est la solution de repli la plus simple ; utilisez Miniconda plus tard pour des environnements reproductibles et la gestion des dépendances d’un projet.

Afficher les commandes pour chaque environnement

Python + VS Code

python -m venv .venv
.venv\Scripts\activate

Anaconda / Miniconda


conda install numpy pandas matplotlib scikit-learn jupyter
conda create -n ml-project python=3.12          # create an environment
conda activate ml-project           # activate it
conda deactivate              # leave it
conda env remove -n ml-project      # delete it and its packages

conda install numpy pandas matplotlib scikit-learn jupyter

conda install opencv          # install a package
conda install opencv=4.6.0    # a specific version
conda install -c conda-forge opencv   # from a specific channel
pip install opencv-python     # pip also works
conda update opencv
conda remove opencv

Google Colab : rien à installer. Ces bibliothèques sont généralement déjà disponibles ; utilisez %pip install nom_du_paquet si l’une d’elles manque.
